# GeMilla

A collaborative project between Danny and GeMilla.

## Description

This project is a Node.js Express server that serves as the foundation for our collaborative work.

## Getting Started

### Prerequisites

*   Node.js
*   npm

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/mrdannyclark82/GeMilla.git
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```

### Usage

*   Start the server:
    ```bash
    npm start
    ```
*   Run the tests:
    ```bash
    npm test
    ```
*   Lint the code:
    ```bash
    npm run lint
    ```
*   Format the code:
    ```bash
    npm run format
    ```
